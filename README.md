# ZYVORA ULTRA

Premium cyber-neon gaming hub for the Zyvora universe.

## Website

The website is a self-contained `index.html` landing page with:

- Zyvora Ultra hero section
- Play Now and All Games navigation
- Featured Zyvora Pixel Mission Ultra 9K section
- Game hub cards
- Responsive mobile/desktop layout
- Future games section
- About Zyvora section
- GitHub link
- Lightweight vanilla HTML/CSS/JavaScript

## Run locally

Open `index.html` in a browser.

## GitHub Pages

In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub Pages can then serve the `index.html` file from the repository.
